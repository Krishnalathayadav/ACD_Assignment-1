# ACD Assignment-1

## Automata Theory Programs in Python

This repository contains Python implementations of fundamental concepts in Automata Theory.

### Programs Included

#### 1. DFA (Deterministic Finite Automaton)

* Implementation of a DFA in Python.
* Demonstrates state transitions for a given input string.
* Displays start state, transition path, final state, and acceptance/rejection result.

#### 2. NFA (Non-Deterministic Finite Automaton)

* Implementation of an NFA in Python.
* Handles multiple possible next states for a given input.
* Shows all current states and transitions during execution.

#### 3. NFA to DFA Conversion

* Implementation of the Subset Construction Algorithm.
* Converts an NFA into an equivalent DFA.
* Generates DFA states and transition table automatically.

### Concepts Covered

* Finite Automata
* Deterministic Finite Automata (DFA)
* Non-Deterministic Finite Automata (NFA)
* State Transitions
* Accept States
* Subset Construction Method
* NFA to DFA Conversion
